## Share useful prompts and interpret intent carefully

We use the name Prompt Charity to combine sharing useful prompts with charitable interpretation: understand the strongest reasonable version of a user's intent, clarify ambiguity, and preserve their constraints. Read [about the name](/prompt-charity/en/about/).

The library starts with plans for review and contains implementation instructions to follow after explicit approval. See [getting started](/prompt-charity/en/getting-started/) and the [prompt template](/prompt-charity/en/prompt-template/).
